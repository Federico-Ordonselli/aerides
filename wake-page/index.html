What it is

Aerides is a multi-tenant web app where gaming groups (guilds, clans, tabletop tables) organize their sessions: events with role-based slots, sign-ups, approvals and automatic waitlists.

When a seat frees up, the first person on the waitlist is promoted and sees it live, without reloading. Groups get email and Discord reminders, an audit log and attendance statistics.

Built with Java 21, Spring Boot 4, PostgreSQL and Angular, tested with Testcontainers and Playwright, shipped with Docker and GitHub Actions.
